# Stack Bowls：现有结果评估

**结论：现有数据能区分释放后的小量运动和末态几何重叠；还不能判断哪个引擎更忠实于原始轨迹。**

本报告只读取既有同版夹爪 r3 的一对轨迹：MuJoCo 4.0.0 CPU 与 SAP Internal 2325082 + Newton Convex。单 episode，R=1。评估脚本不启动模拟。

共同主窗口：9.06–9.56 s，为参考视频最后 0.5 s；10 ms 状态采样，各碗 51 点。两引擎使用同一个窗口。

## Physical Fidelity

Object-trajectory error、Final-pose error 暂未评估。视频有估计潜力，但未形成带不确定度的可靠三维参考；有效参考覆盖为 0/720 物体帧，最终 0/3。不能比较谁更接近原始演示。

已看过头部视频关键帧和 7 个时刻的三视角图，共 21 张多视角图。上层碗及部分搬运段可见，值得估计位置和轴线；最终下层碗遮挡明显。这里的 0 覆盖率表示尚无已接受的定量三维估计，并不表示视频全部不可用。参考不确定度暂未量化，因此误差保留为空，不能把两引擎彼此接近当成复刻误差小。

## Simulation Consistency

### 释放后稳定性

以下 RMS 为速度向量模长的时间 RMS，非各分量 RMS 的平均。碗0=初始中间／底层；碗1=初始左侧／上层；碗2=初始右侧／中层。

| 碗 | 引擎 | 线速度 RMS（mm/s） | 角速度 RMS（rad/s） | 0.5 s 净漂移（mm） |
|---|---|---:|---:|---:|
| 底层 | MuJoCo | 0.0342 | 0.00109 | 0.0171 |
| 底层 | SAP + Newton | 0.0298 | 0.00100 | 0.0001 |
| 中层 | MuJoCo | 0.3269 | 0.00646 | 0.1624 |
| 中层 | SAP + Newton | 0.0540 | 0.00109 | 0.0135 |
| 上层 | MuJoCo | 0.9804 | 0.01995 | 0.4894 |
| 上层 | SAP + Newton | 0.0687 | 0.00108 | 0.0290 |

这段窗口内 SAP 的上层和中层碗运动更小；MuJoCo 主要表现为小幅缓慢漂移。两者都没有肉眼明显的剧烈运动。接触参数和数值实现未做物理等效标定，这些差异不单独构成复刻精度排名。

### 几何有效性：仅有末态采样

| 同一种共同几何采样方法 | MuJoCo（mm） | SAP + Newton（mm） |
|---|---:|---:|
| 底层／中层碗穿透下界 | 0.0540 | 1.5766 |
| 上层／中层碗穿透下界 | 0.0305 | 0.4658 |
| 所有已检查物体对的最大采样下界 | 0.0895 | 1.5766 |

范围：仅 t=10.56 s 一帧，1024 个凸体顶点／碗，检查三碗之间和碗／桌面。数值是采样穿透下界，不是精确穿透深度，也不代表全程最大穿透。局部壁厚和穿墙检查未完成，所以不能据此给出严重程度或有效成功的最终判定。共同几何为 CoACD 近似，也不能把这个数值直接当成真实碗的穿透量。

### 接触连续性

未评估。现有成对比较没有按物体对的有效接触时间序列，不能以总接触点数代替。

## Task Outcome

参考和两引擎的视频观察均为释放后保持三碗叠放，视觉 outcome agreement 为真。严格 valid_success、有效 outcome agreement、false success/false failure 留空：尚未完成局部壁厚／明显穿透与持续托举排除检查。这里不使用官方 policy 门槛，也不以最终倾角是否大于 10° 判失败。

## 可以区分什么

已有数据可区分末态共同几何采样重叠和释放后细小运动；最终视觉结果没有拉开差距。SAP 更静不等于更接近原示范，MuJoCo 采样穿透更少也不能单独证明真实复刻更好。没有足够证据给出 Physical Fidelity 排名或多 episode 复刻成功率。
