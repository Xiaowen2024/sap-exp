## 实验设计

参考来自 RoboDojo 官方仿真示范。源帧 225–549（9.00–21.96 s），闭合笔记本从原支架上由左手拾取、搬运，换给右手插架并释放；不含耳机或关盖。两引擎各连续回放一次，换手时不重置物体；末尾追加 1.5 s 观察。

固定同一初始场景、几何、质量/惯量、摩擦、控制器及机器人/夹爪运动输入；完整流程不再调参。机器人轨迹是输入，笔记本运动是评价对象。按物理保真度、模拟一致性和任务结果三类报告；夹爪跟踪、最大抬升和手中相对 COM 变化仅作诊断。

起点由图像与标定重建，不是官方物体位姿真值。闭合笔记本采用单凸包，初始支架采用分区凸包近似；建模与输入跟踪误差会限制比较的解释。单条示范不报告成功率。

## 结论

- **任务结果区分度有限：**两边都观察到插入、完全释放后保持，与参考的观察结果一致；撤手后夹爪承载力均为 0 N。局部壁厚、穿墙和整体几何有效性复核未完成，严格有效成功仍未判定。
- **已有数据能区分局部表现：**MuJoCo 与竖架、初始支架的采样穿透更少；SAP 在当前抓持窗口内接触更连续，在共同释放后窗口内更静。线速度 RMS 分别为 MuJoCo 1.908 mm/s、SAP 0.962 mm/s。
- **不能判断谁复刻得更准：**可靠参考物体轨迹与末态位姿尚未建立，两项参考误差均未评估。更静或部分物体对穿透更少，都不能单独证明哪个引擎更真实。

### 1. Physical Fidelity

Object-trajectory error 与 Final-pose error 均未评估。没有接纳的可靠 estimated reference：轨迹覆盖 0/325 个物体帧，最终窗口 0/12 帧、0/1 个物体。末态多视角拟合残差 6.90 px 未通过 2 px 接纳线，不确定度尚未建立；这不是模拟误差。0 覆盖率不代表图像全部不可见。初始化拟合、手中相对变化、夹爪跟踪误差或两引擎差值都不能代替物体对参考的误差。

### 2. Simulation Consistency

#### Geometric validity

共同凸几何观察器覆盖回放 0–14.46 s，每 10 ms 一帧，共 1447 帧。以下是最大采样凸组件对穿透的上下界，单位 mm，不是精确并集穿透，也不是连续时间峰值。

| 物体对 | MuJoCo（mm） | SAP（mm） |
|---|---|---|
| 笔记本—竖架 | 0.077–0.129 | 1.369–1.396 |
| 笔记本—初始支架 | 0.108–0.109 | 2.414–2.504 |

这两个静态物体对上 MuJoCo 的采样重叠更少。但部分夹爪边角接触区间较宽，局部壁厚/穿墙审核未完成，不能据此判定整体几何有效性或有效成功。

#### Contact continuity

逐物体对统计预先声明的持续抓持/支撑窗口。1 ms 接触采样，承载阈值 0.01 N；另查 0.001/0.1 N，所列结果不变。候选接触与承载接触分开。

| 物体对 | 回放窗口 | MuJoCo duty / 最长断触 | SAP duty / 最长断触 |
|---|---|---|---|
| 笔记本—左指 7 | 3.2–7.6 s | 99.55% / 13 ms | 100.00% / 0 ms |
| 笔记本—左指 8 | 3.2–7.6 s | 98.93% / 40 ms | 100.00% / 0 ms |
| 笔记本—右指 7 | 8.3–11.6 s | 100.00% / 0 ms | 100.00% / 0 ms |
| 笔记本—右指 8 | 8.3–11.6 s | 99.94% / 1 ms | 100.00% / 0 ms |
| 笔记本—竖架 | 12.3–14.46 s | 99.95% / 1 ms | 100.00% / 0 ms |

架子支撑窗口包含追加观察段，两边窗口相同。正常接触切换不自动判错；双指承载不完整也不能直接判为脱手。接触恢复次数、候选 duty、阈值敏感性保存在 JSON。

#### Post-release settling

**主窗口使用参考视频内相同的释放后窗口：源时间 21.50–21.96 s，即回放 12.50–12.96 s。** 每引擎 461 个 1 ms 状态样本。RMS 为 sqrt(integral(||v||² dt)/duration)。

| 共同源视频窗口内的物体运动 | MuJoCo | SAP |
|---|---|---|
| COM 线速度 RMS（mm/s） | 1.908 | 0.962 |
| 世界角速度 RMS（rad/s） | 0.04497 | 0.01593 |
| COM 净漂移（mm） | 0.23660 | 0.00423 |
| 线速度峰值（mm/s） | 9.851 | 5.574 |

两者运动量均较小，SAP 在此窗更静；稳定不等于最终位姿正确。追加尾窗 [13.96,14.46] s 的结果仅作补充（线速度 RMS 为 4.019 / 0.851 mm/s），不与主窗口混用。路径长度和倾角波动本次没有现成有效结果，留空。

### 3. Task Outcome

参考视频观察为插入并完全释放后保持。两引擎在相同源视频最终窗口内均观察到保持，追加观察段也保持；撤手后夹爪承载力均为 0 N，视频中夹爪已离开。

| 逐 episode 判断 | MuJoCo | SAP |
|---|---|---|
| 插入、完全释放后保持：视频观察 | 是 | 是 |
| Observed outcome agreement | 与参考一致 | 与参考一致 |
| 严格 valid_success / 有效 outcome agreement | 未判定 / 未判定 | 未判定 / 未判定 |

持续托举已有排除证据，但局部壁厚/穿墙及整体几何有效性复核未完成，因此 valid_success 和严格 agreement 留空，不把缺项算成通过或失败。参考观察为成功，false success 在该标签下不适用；模拟有效结果未判，false failure 不填写。单 episode 不报成功率。
