# 闭合笔记本完整 run：按叠碗 SOP 评估

**结论：可以区分部分几何重叠、接触连续性和释放后的小量运动；暂不能比较对参考的复刻精度，严格有效成功仍待判定。**

沿用用户提供的[叠碗评估 SOP](../stack-bowls/sop.md)，只整理已完成的 MuJoCo 4.0.0 Warp 与 SAP Internal 2325082 + Newton Convex 连续回放。每引擎一次，未新增模拟或调参。机器人轨迹是输入，笔记本运动是评价对象。原先最大抬升、手中相对 COM 变化和夹爪误差不再混入物体质量主表。

源帧 225–549（9.00–21.96 s），闭合笔记本从原支架上由左手拾取、搬运、换给右手插架并释放；不含耳机或关盖。dt=1 ms，共 14.46 s，末尾 1.5 s 为追加保持。沿用短片段选定参数：MuJoCo solref=(0.002,1)，SAP pair ke=100000 N/m、pair tau=0.02 s；其他几何、质量/惯量、μ、控制器与输入固定。

Object-trajectory error 与 Final-pose error 均未评估。没有接纳的可靠 estimated reference：轨迹覆盖 0/325 个物体帧，最终窗口 0/12 帧、0/1 个物体。末态多视角拟合残差 6.90 px 未通过 2 px 接纳线，不确定度尚未建立；这不是模拟误差。0 覆盖率不代表图像全部不可见。初始化拟合、手中相对变化、夹爪跟踪误差或两引擎差值都不能代替物体对参考的误差。

### Post-release settling

**主窗口使用参考视频内相同的释放后窗口：源时间 21.50–21.96 s，即回放 12.50–12.96 s。** 每引擎 461 个 1 ms 状态样本。RMS 为 sqrt(integral(||v||² dt)/duration)。

| 共同源视频窗口内的物体运动 | MuJoCo | SAP |
|---|---|---|
| COM 线速度 RMS（mm/s） | 1.908 | 0.962 |

## 输入与过程诊断（不进入物体质量评分）

左夹爪最大位置误差 4.11 / 4.43 mm，姿态误差 8.33° / 5.10°，均超过原先 5° 检查线。输入实现限制会影响因果解释，但它不是物体轨迹误差，也不自动等于任务失败。拾取时左指与原支架接触，原生法向力峰值约 122 / 75 N，需结合重建几何理解。最大抬升、COM 在夹爪系的变化、双指合并统计保留在[过程诊断](full-stages.json)，不作参考误差替身。

## 可以区分什么

现有数据能区分这两个静态物体对的采样几何重叠、接触连续性和释放后运动；视觉放入结果一致。参考物体误差未建立、严格有效成功尚未判定，仍不能排名复刻精度。不能仅因 SAP 更静或 MuJoCo 某些物体对穿透更少，就断言谁更真实。
