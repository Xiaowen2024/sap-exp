# RoboDojo：闭合笔记本完整拾取与插架（主结果）

更新：2026-11-18。单 episode，每配置只回放一次。比较 MuJoCo 4.0.0 Warp 与 SAP Internal `2325082` + Newton Convex，Warp 1.18.0，RTX 4090。只处理已关闭的笔记本，不含耳机或关盖。官方示范来自仿真，不是真实机器人。

## 目前结论

**主结果是从拾取开始的完整 run。** 沿用已选定参数，每个引擎连续回放一次，没有重新调参或中途重置。两边都观察到拾取、搬运、换手、最终放入和撤手，二元任务结果没有区分度。

过程存在差异：SAP 接触更连续、末态更静；MuJoCo 的竖架穿透更小（0.077–0.129 mm，对比 SAP 1.369–1.396 mm）。两边均未通过原先的夹爪姿态跟踪检查，因此不能直接排名严格复刻精度。

插入短片段只保留为参数选择的补充记录：SAP 用 2 组配置、MuJoCo 用 3 组，提前停止；不把该短片段的较小穿透数值当作完整 run 的结果。

## 穿透、接触与参考误差的口径

状态与物体对接触力以 1 ms 保存；承载阈值 0.01 N，另查 0.001/0.1 N。候选接触不等于承载接触。几何观察器每 10 ms 检查共同凸几何；短片段 547 帧，连续流程 1447 帧。

表中穿透是最大“凸组件对分离深度”的上下界：交集最大内切球半径的两倍给出下界，沿凸面法向分离的位移给出上界。它不是整组凸包并集的精确最小分离深度，也不是连续时间最大值；部分边角接触的区间较宽，不将上界当成实测深度。

最初 FCL 观察器的深度返回值违反独立分离上界，已作废，未用于本报告；保留了失效证据与原始调试日志。原先 16 块的架子凸分解使槽口缩窄 1.5–4.3 mm，在动力学前弃用；现用底座与两侧壁，12 个截面的最大采样边界误差约 0.0174 mm。

官方没有逐帧物体位姿真值。末态多视角估计尝试的重投影残差约 6.90 px，未达到 2 px 的接纳门槛，因此 trajectory/final-pose error 留空，可靠评价参考覆盖率为 0。初始化图像拟合不冒充独立物体轨迹真值。当前数字能描述内部几何、接触与稳定性差异，不能给出物理保真度的确定排名。每配置一次、单 episode，不给成功率或性能置信区间。

## 与之前 RH20T 放盘子的关系

旧盘子比较同样从已经夹住开始，盘壁 8.3 mm 与笔记本约 9 mm 也接近，所以不能把起点截取或厚度当作主要解释。旧盘子由 25 个凸块组成，指垫跨在接缝上；硬接触下的冲突法向导致 MuJoCo 脱手。其软参数其实能放入片段，却在整段搬运时打滑；当时要求同一组参数兼顾两阶段。旧参考还是真实藤编物体，有局部变形。本实验的板状凸包没有该接缝，属于较干净的对照，没有重现旧实验的困难条件。
