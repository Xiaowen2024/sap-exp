# Task matrix 05: middle-box ejection / retention

| Field | Definition |
| --- | --- |
| Physical mechanism | Coupled static-friction constraints in a multi-contact stack |
| Setup | Push the middle box of a stacked-box scene under a controlled force condition |
| Environment condition | Define cases expected to retain the middle box and cases expected to eject it |
| Expected outcome | Match the specified retained or ejected final state |
| Real-world reference | Optional matched physical-stack trial |

## Task-specific metrics

| Metric | Definition |
| --- | --- |
| Expected-outcome agreement | Fraction of conditions whose final middle-box state matches the pre-specified retained/ejected outcome. |
| False-retention / false-ejection rate | Respectively: expected ejection but retained; expected retention but ejected. |

The shared metrics explain the mechanism behind an incorrect task outcome. This
task matrix only scores whether the final physical regime is correct.
